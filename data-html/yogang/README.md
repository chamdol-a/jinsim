# 대학 자료실 (전국 대학 공식 입시자료 뷰어)

진심 입시정보 → **진심 데이터 → 대학 자료실** 에 들어가는 페이지입니다.

## 파일 구성

| 파일 | 하는 일 | 손대야 하나? |
|---|---|---|
| `index.html` | 화면 전부 (검색·필터·목록·미리보기) | 디자인을 바꿀 때만 |
| `yogang-data.js` | 어디가(adiga)에서 긁어온 대학별 자료 링크 | **자동 생성 — 손대지 않음** |
| `extra-links.js` | 전공가이드북·전형 안내 책자 등 직접 등록하는 자료 | **여기에 추가** |
| `univ-meta.json` | 대학별 입학처 홈페이지 주소 | 주소가 바뀔 때만 |

## 1) 자료 갱신 (어디가 자동 수집)

```bash
python ipsi-site/tools/fetch_yogang.py
```

- 기본은 **2028 + 2027학년도**를 함께 받아옵니다. 특정 학년도만 받으려면 `python ipsi-site/tools/fetch_yogang.py 2027`.
- 2~4분 걸리며, 끝나면 `yogang-data.js` 가 새로 만들어집니다.
- **매주 월요일 새벽 6시(한국시간)에 GitHub Actions가 알아서 실행**하고, 바뀐 게 있으면 저장소에 커밋합니다.
  (`.github/workflows/update-yogang.yml`) 즉시 돌리고 싶으면 GitHub 저장소 → Actions → '대학 자료실 갱신' → Run workflow.

## 2) 전공가이드북·안내 책자 추가

`extra-links.js` 의 `items` 안에 대학 이름을 키로 한 줄 넣으면 끝입니다.

```js
"성균관대학교[본교]": [
  { title:"전공안내 책자", url:"https://...", type:"guide", year:"2027" }
],
```

- 대학 이름은 화면 목록에 보이는 이름 그대로. 캠퍼스가 여럿이면 `[본교]` / `[제2캠퍼스]` 까지 적습니다.
- `type` : `guide`(전공가이드북·책자) / `plan` / `susi` / `jeongsi` / `prior` / `essay`
- 저장하고 새로고침하면 바로 보입니다. `yogang-data.js` 를 다시 받아도 이 파일은 덮어쓰이지 않습니다.

## 3) 배포

`git add -A; git commit -m "..."; git push` → 1~2분 뒤 https://chamdol-a.github.io/jinsim/ 에 반영됩니다.

## 출처

- 시행계획 / 수시·정시 모집요강 / 선행학습영향평가 / 대학별 고사자료(논술·적성) / 재외국민·외국인 모집요강
  → 교육부·한국대학교육협의회 **대입정보포털 어디가**(adiga.kr)에 각 대학이 제출한 원본 파일 링크.
- 전공가이드북 · 전형별 안내 책자 → 각 대학 입학처가 발행·게시한 자료 링크.

미리보기는 구글 문서 뷰어를 씁니다. 원본이 한글(HWP) 파일이면 미리보기가 열리지 않으므로
'새 창에서 열기' 또는 '내려받기'를 안내합니다.
